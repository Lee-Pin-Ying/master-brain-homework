01 / DATA FIRST

先確認拿得到什麼，再決定用什麼模型。

資料用途目前狀態
時間、GPS 位置、速度建立基本時間序列與 GPS 基準待匯出活動檔確認
步頻、步長及其來源評估動作速度模型與循環依賴待確認是否逐秒、是否依賴 GPS
原始加速度與角速度研究動作特徵或慣性方法不能預設歷史活動檔含有
GNSS 品質／原始量測可靠度判斷或緊耦合融合待確認設備及 API 可取得性
獨立速度／距離參考驗證估計是否正確尚未取得

第一個可執行動作：拿一份活動檔檢查欄位與時間解析度，再調整研究範圍。

S01：輸入與驗證資料；目前資料缺口。
02 / EVALUATION PLAN

穩定、準確、即時，分開驗證。

準備比較的基準

  1. 原始 GPS 速度。
  2. 單純平滑的 GPS。
  3. 動作資訊估計速度。
  4. GPS 與動作資訊融合。

依實際可取得的資料決定可執行項目。

建議評估項目

  • 有獨立速度參考時：速度 MAE／RMSE。
  • 加減速時：反應延遲與失真。
  • 全程：累積距離誤差。
  • 情境：空曠與遮蔽路段分開分析。
已知跑道總長可驗證總距離，但不能自動當作每一秒的速度真值。不能用同一段失準 GPS 同時當輸入與正確答案。
此段為研究建議，尚未執行。依據：驗證概念、S01 與 S02 的評估設計。
